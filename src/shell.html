连接清华大学学位论文服务系统

网页将显示在这里。若加载失败，请检查网络后点击刷新。

下载

打开 PDF 预览后点击上方“保存当前 PDF”，在系统对话框中选择保存位置。保存的是当前预览文档，保留原有水印。

检索参数已自动修正

网站中的“学科名”会按接口实际字段“专业”提交。无需添加 %、* 或引号。

浏览与下载

使用上方检索栏，或直接使用网页内的高级检索。点击论文标题会在新标签页打开；登录窗口也会保留在应用内。

在 PDF 预览页等待正文出现，点击工具栏“保存当前 PDF”。右侧“下载记录”只显示任务状态，并不是保存按钮。只保存当前已获准加载的 PDF，保留水印，不获取无水印版本。

应用使用网站原有的预览与下载功能。下载权限、登录验证、校园网或 VPN 要求仍由清华网站决定，不绕过权限。

登录与数据

登录状态保存在本机应用数据目录，与系统浏览器相互独立。密码由网站处理；本应用不读取或记录密码。不要在共享电脑上保留登录。

打不开网页？

确认网络、校园网/VPN可用，再点击刷新。外部网站会在确认后交给系统浏览器；应用不忽略证书错误。

快捷键

Ctrl / ⌘ + T：新标签页
Ctrl / ⌘ + W：关闭标签页
Ctrl / ⌘ + R：刷新
